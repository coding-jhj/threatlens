# 정답 목록 블라인드 재판정 (AI 교차검증)

> 사람 검수가 아닙니다. 정답을 쓴 에이전트와 **다른** 에이전트가 `structures.md`만 보고 정답을 새로 작성했습니다(규칙·엔진·기존 정답은 보지 않도록 지시). 같은 계열 모델이라 같은 편향을 공유할 수 있습니다.

## 의미

- 기존 정답 29개는 **모두** 블라인드 목록에서 대응하는 항목이 있었습니다(재현율 방향의 오류는 없음).
- 반대로 정답 목록이 **빠뜨린 것**이 13개 있었습니다(블라인드 39개 중 약 1/3). 지금 평가표의 재현율 72%는 "29개 기준"이며, 보충 후보를 포함한 약 42개 기준으로는 더 낮아집니다. 이 13개는 **채점에 넣지 않았습니다**(정답을 바꾸면 이전 수치와 비교가 깨지기 때문).
- 13개 중 규칙이 없는 주제: 무제한 소비(LLM10), 시스템 프롬프트 노출(LLM07), 렌더링 URL·이미지 유출, 샌드박스 탈출, 연락처·발신자 위조, IT/OT 망 분리, 경보 억제, AI 장애 시 fail-safe, 감사 추적. G6(규칙 28→40) 후보로 넘깁니다.

## 블라인드가 낸 13개

- 문서 QA: 유도 질문으로 시스템 프롬프트·내부 문서 추출 / 긴 문서·반복 질의로 비용 소진
- 고객상담: 대량 자동화 요청에 따른 비용 폭증·API 남용 / AI 출력이 API 인자·화면에 검증 없이 쓰여 인젝션·XSS
- 코드 에이전트: 실행 환경에서 호스트·내부망으로 이동 / 저장소 파일(README·이슈)에 심은 지시문
- 메일 비서: 링크·이미지 로딩으로 데이터를 실어 보내는 제로클릭 유출 / 연락처·발신자 위조 / 첨부·링크의 악성 콘텐츠
- 공정 운전 보조: 거짓 안전 상태 보고·경보 억제 / IT→OT 침투 / AI 장애·모델 변경과 fail-safe 부재 / 제어 호출 감사 추적 부재

## 판정 결과 (AI 판정자 3명, 다수결)

사람 대신 서로 모르게 일한 AI 판정자 3명이 부분 일치 4건과 보충 후보 13건을 따로 판정했습니다. 2명 이상이 같은 답을 낸 것만 따랐습니다. 사람 전문가 판정이 아닙니다.

| 대상 | 판정 | 비고 |
|---|---|---|
| P1 API 과다 호출 ↔ IDOR | 다른 위협 (3/3) | 원인·대책이 달라 추가 |
| P2 검증 없는 실행 ↔ 최소 권한·승인 부재 | 다른 위협 (3/3) | 추가 |
| P3-a 렌더링 유출 | 다른 위협 (3/3) | mail-X7과 같은 항목이라 한 번만 셈 |
| P3-b 잘못된 내용 발송 | 같은 위협 (3/3) | 기존 정답에 포함 |
| P4 위험 설정값 직접 쓰기 | 같은 위협 (2/3) | 기존 정답에 포함 |
| 보충 후보 13건 | 추가 5건: doc-qa-X1(2/3), doc-qa-X2(3/3), support-X3(3/3), code-X5(2/3), mail-X7(2/3) | 나머지 8건은 찬성 1명 이하라 제외 |

추가분은 `ground-truth-additions.json`에 따로 두었습니다(기존 정답은 바꾸지 않습니다). P1·P2와 합쳐 보충 7개를 넣은 **v2** 수치는 시험(`src/eval/v2.test.ts`)이 고정합니다.

| 기준 | 정답 수 | 느슨 재현율 | 엄격 재현율 |
|---|---|---|---|
| v1 (기존) | 29 | 21/29 = 72% | 15/29 = 52% |
| v2 (보충 7개 포함) | 36 | 25/36 = 69% | 19/36 = 53% |

보충 7개 중 규칙이 잡아내는 것은 4개(느슨)이고, 비어 있는 주제는 LLM07(시스템 프롬프트 노출)입니다. 제외한 8건 중 찬성 1명이 있던 주제(IT→OT 침투, fail-safe, 저장소 간접 주입, 발신자 위조, 출력 처리 XSS)는 G6 규칙 확장 후보로 남깁니다.
