# 위험 점수 계산 방법

## 공식
1. 위협 하나의 기본 위험: 높음 15%, 중간 7%, 낮음 2% (`SEVERITY_WEIGHT`)
2. 대응책을 적용하면: 남은 위험 = 기본 위험 × max(10%, 1 − 적용한 대응책 점수 합/100)
   - 대응을 전부 적용해도 위험의 10%는 남습니다. 위험이 0이 되는 구조는 없다는 뜻입니다.
3. AI 노드 점수 = 100 × (1 − Π(1 − 위협별 남은 위험)). 위협이 여러 개 겹칠수록 100에 가까워집니다.
4. 전체 점수 = AI 노드 점수 중 최댓값(가장 위험한 AI 기준), 0~100 정수(반올림)

## 손계산 예시 (테스트에 같은 값이 들어 있습니다)
| 상황 | 계산 | 점수 |
|---|---|---|
| 위협 없음 | - | 0 |
| 높음 1개, 대응 없음 | 0.15 | 15 |
| 높음 1개 + 대응 −30 | 0.15 × 0.7 = 0.105 | 11 |
| 높음 1개 + 대응 −30, −20 | 0.15 × 0.5 = 0.075 | 8 |
| 높음 1개 + 대응 합 100 초과 | 0.15 × 0.1 = 0.015 | 2 |
| 높음 1개 + 중간 1개 | 1 − 0.85 × 0.93 = 0.2095 | 21 |
| 높음 2개 | 1 − 0.85² = 0.2775 | 28 |

## 시안 구조(문서·센서 입력 → AI → 메일·제어 API)에 28개 규칙을 적용했을 때
- 대응 전: 발동 규칙 다수, 점수 높음 (이 값은 화면에서 확인)
- 사람 승인 대응(R-01) 1개만 적용: 71점. 승인 속성이 켜져 "승인 없음" 조건의 규칙들(R-04, R-17, R-22, R-24 등)이 함께 사라집니다.
- 거기에 인터록 대응(R-09) 추가: 65점
- 모든 대응을 적용: 32점 (잔여 위험이 남음)

## 알아 둘 점
- 이 점수는 "알려진 위협 유형이 이 구조에서 얼마나 겹쳐 있는가"를 나타내는 상대 지표입니다. 실제 사고 확률이 아닙니다.
- 가중치(15/7/2%)와 바닥값(10%)은 현재 가정값이며, 최종 평가(E3)에서 정답 목록과 비교해 조정할 수 있습니다.
