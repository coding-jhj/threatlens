# G4 질문 마법사

- 질문 8개(예/아니오): 외부인 입력, 외부 파일·웹 읽기, 민감정보 접근, 밖으로 보내기, 코드 실행, 사람 승인, 설비 연결, 독립 안전 장치.
- 답 → 부품·화살표·속성은 `src/wizard/wizard.json` 규칙표로만 만듭니다(AI 호출 없음). 기본 구조는 사용자 → AI 에이전트이고, "예"마다 부품·연결·속성이 덧붙습니다.
- 마지막 화면에서 점수와 행동 계획 개수를 보여 주고 [도면 열기]로 캔버스에 배치합니다. 이후 자유롭게 편집하고 Ctrl+Z로 되돌릴 수 있습니다.
- 진입: 첫 안내창 [질문 8개로 시작], 빈 캔버스 [질문 8개로 시작], 도구줄 [질문으로 시작].
- 검사: 답 조합 256가지를 전수로 돌려 AI 1개 이상·끊긴 부품 없음·중복/자기 연결 없음·점수 계산 가능을 보장(`src/wizard/wizard.test.ts`). 화면 시험 `e2e/g4.spec.ts`가 8문항 완료와 구조·점수·행동 계획 표시를 60초 안에 확인합니다.
- 한계: 질문 8개는 구조를 거칠게 추정할 뿐입니다(예: 설비 연결 시 센서·제어 API·PLC를 고정 배치). 실제 구조와 다르면 캔버스에서 고쳐야 합니다. "독립 안전 장치" 답은 사용자의 주장이며 도구가 검증하지 않습니다.
